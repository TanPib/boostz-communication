# boostz-communication

Social media for Boostz (TCG collection app): the Instagram (@boostz.app) and TikTok ("Boostz") posts, their source templates, and the price data some of them need. The app itself lives in `TanPib/boostz-mobile`. The user is French and writes in French; everything published is French, while code and comments are English.

This repo is **public on purpose**: Metricool fetches each image and video from its `raw.githubusercontent.com` URL. Anything committed is readable before its publication date.

## Autonomy

On 05/10/2026 the user gave standing approval for every action in this work: producing, scheduling, moving and replacing Metricool posts, and changing the communication site. Do not ask before acting; report what was done. `PLANNING.md` is the approved plan to produce, in date order. Metricool is on a paid plan since 13/10/2026: the free plan's 20 published posts a month per network no longer limit the plan. Start with its "À reprendre" section when there is one.

## "Fais-moi une publication"

When the user asks for a post without saying which kind, this is the workflow:

1. Read `TYPES.md` (the menu, the rotation rules, the history) and the Metricool calendar (`getScheduledPosts`, brand `7193220`, timezone `Europe/Paris`) for posts not yet in the history.
2. Show the menu as a table: number, type, format, trend, last published. Recommend two or three, using the rotation rules: alternate Reel and carousel, don't repeat the last type, vary the game. Let the user pick a number and, optionally, a subject.
3. Build it from the type's template in `gabarits/` (edit the content in place; git keeps the previous edition). Render with `cd gabarits && node rendu.mjs <page>.html images|plans|video`. **Look at every slide or still yourself** and fix overlaps, clipping and orphan words before showing anything.
4. Send the slides with SendUserFile and iterate until the user approves.
5. Export: carousel slides as **JPEG**, because the Instagram and TikTok APIs refuse PNG for photos (`ffmpeg -i x.png -pix_fmt yuvj444p -q:v 2 x.jpg`, 4:4:4 so thin coloured text survives), into `images/<publication date>-<slug>/1-…jpg`. Videos as H.264 MP4 into `videos/<date>-<slug>.mp4`, **always 4:2:0** (`-pix_fmt yuv420p -profile:v high`): on 08/10/2026 the user's phone played a 4:4:4 Reel with sound but no picture, and every Reel that had been through `accroche.sh` was 4:4:4 (fixed in the script, the 22 files re-encoded). **Every Reel opens on its hook** (asked on 06/10/2026): add an entry to `gabarits/accroche.html` (the strongest image and line, all visible at frame 0, inside the 3:4 band the grid keeps), then `sh outils/accroche.sh <video without hook> <entry> <music style> videos/<date>-<slug>.mp4`, which puts the hook in front (held 1.5 s, then its content lifts and fades and the video dissolves in on the same background: never a hard cut, asked on 06/10/2026), re-mixes the track and writes the cover to `images/couvertures/<date>-<slug>.jpg`. Schedule Reels with that cover as `videoThumbnailUrl` (Instagram, Facebook, TikTok). Commit only those paths, push, then check every raw URL answers 200 before scheduling.
6. Pick the slot: no other post the same day, weekdays 10:00 by default (TikTok's best slot for the account is Thursday 10:00, second peak 18:00; Instagram has no data yet). Check `getBestTimeToPostByNetwork` for TikTok.
7. Schedule **one post per network** (`createScheduledPost`), so each carries its own hashtags: Instagram type `POST` (carousel) or `REEL`, with alt text per image; TikTok always with `tiktokData.title` (required, ≤ 90 characters), **never `autoAddMusic`** (on 26/10/2026 it put explicit rap with insults on the Méga-Dracaufeu X carousel: TikTok picks the track and the API cannot choose it): **a TikTok carousel stays a photo post with `autoPublish: false`** (chosen by TanPib on 30/10/2026, over a video): at the scheduled time Metricool sends him a push notification and he finishes the post in the TikTok app, choosing the sound himself; TikTok Reels keep `autoPublish: true` and their embedded track. `outils/diaporama.sh` (the slides as a video with our own track) stays for an emergency repost, as on 26/10; **Facebook** (asked on 05/10/2026) `facebookData.type` `POST` for a carousel, `REEL` for a video, same caption as Instagram. `autoPublish: true`. **Declare the content AI-generated everywhere** (asked on 06/10/2026, because it is): `instagramData.isAiGenerated: true` on every Instagram post, Reel and story, `tiktokData.isAigc: true` on every TikTok video (TikTok ignores it on photo posts). Facebook has no such field in the API.
   **Intellectual property** (asked on 06/10/2026): every post names the owners of the games it shows. Add the post to `outils/propriete.py` (its games and the credit of any third-party photo), then put `python3 outils/propriete.py <date>` in `firstCommentText` on Instagram and Facebook, and at the end of the caption on TikTok (no first comment through the API).
   Then **one story post for Instagram and Facebook together**, at the same time, with no text (`instagramData.type` and `facebookData.type` `STORY`). **Never the video itself** (asked on 07/10/2026): the story is the post's cover, animated, 7 s, with the post's music: add the post to `STORIES` in `gabarits/story-anime.html` (its Reel cover or its carousel's `1-couverture.jpg`), then `sh outils/story-anime.sh <date>-<slug> <the Reel's MP4, or a music style> videos/<date>-story-<slug>.mp4`. It says "Le Reel complet sur le profil 👆" / "Le post complet sur le profil 👆": neither API nor Metricool can add a link sticker to a scheduled story (the user chose this over adding the link by hand). TikTok stories cannot be scheduled through Metricool's API.
8. Add the post to the history in `TYPES.md` and to the table in `README.md`, commit, push.

Never overwrite a scheduled post with `updateScheduledPost` without reading it first: the user edits them by hand in Metricool (they add the Instagram music themselves, which the API only supports on Reels).

## What the user has asked for, every time

- **Decorations never touch text**: the dashed path and the ghost card outlines go in empty space, never across a sentence, a source line or the wordmark (05/10/2026: a source line on the Charizard post was crossed). Check it on every slide and still.
- **Music on every post, every network** (05/10/2026): cool, soft, never aggressive, matching the post's style. TikTok and Facebook have no music API for videos, so the track is **embedded in the MP4**, mixed low (about −18 LUFS, fade in and out). **Every** Instagram Reel also gets a library track via `audioConfiguration` (`videoVolume: 0`, `audioVolume: 60`), never left empty (06/10/2026: "ajoute toujours de la musique quand tu en as la possibilité"); the one exception is the Collect Aura opening Reel (15/12), which keeps its own soundtrack (TanPib, 20/10/2026): search a soft term ("spooky lofi", "christmas lofi"), the error lists candidates, then pass the numeric `audioId`. Before scheduling, check that every MP4 is audible (`ffmpeg -i x.mp4 -af volumedetect -f null -`, max volume above −30 dB); `outils/musique.mjs` now refuses to write a silent track. Carousels: **never TikTok's `autoAddMusic`** (26/10/2026, see above): TikTok photo posts go out with `autoPublish: false` and TanPib picks their sound in the app; Instagram and Facebook carousels cannot get music through the API either (the user adds Instagram's by hand). Every story is a short MP4 (the animated cover + the post's music, `outils/story-anime.sh`) so it carries sound. Runway music generation needs a paid plan (refused 05/10/2026): compose original tracks in code instead, never third-party audio. The tracks are **lo-fi** (asked on 06/10/2026: "des sons vraiment en mode low-fi"): `outils/musique.mjs` swings a slow groove under jazzy ninth chords, a dusty boom-bap kit and a sparse lead, then crushes the drums, ducks the music under the kick and adds tape wow, a dark filter, vinyl crackle and hiss. Give each new post its own style (tempo, chords, lead, kit, dust, `comp`) so they don't all sound alike. Never the same chord stab on every bar (06/10/2026: "ce DON DON qui se répète" gets tiresome while scrolling): `comp` holds the chords as soft swells, breaks them into a few spread notes, or plays one long chord every other bar. The vinyl crackle stays faint (asked the same day). The launch Reel (16/10) has an upbeat, **clean** track, asked for that video only ("plus fun et entraînant", then "limite flippante" with the lo-fi wobble): then "ratée" again (random notes sound aimless): style `lancement`, 104 BPM, C G Am F strummed on a ukulele (`comp: 'strum'`), a **written** glockenspiel melody (`melody`, from `MELODIES` in `musique.mjs`), claps and a shaker (`pop` kit), and `clean: true`, which drops the tape wobble, the vinyl and the crushed drums. Use it as the model when a post needs a cheerful track; lo-fi treatment makes happy music sound eerie.

## Templates (`gabarits/`)

Plain HTML pages, one per type, sharing `fonts/` (OFL fonts: Outfit for the wordmark, Poppins, Exo, DM Sans, Sora), `assets/` (card backs, game emblems, flags, fan logo, app icon), `shots/` (real app screenshots) and `posts-emblems.js`. A carousel page draws one `.p` element per slide; a video page exposes `window.TOTAL` and a deterministic `window.render(t)`.

- `stickers.js` holds the shared sticker-style helpers (tokens, game colours, `wordmark`, `st`, `card`, `back`, `track(k, y, amp)`, `closing`) and two builders: `carousel(slides)` and `reel(html, total)`, where an element animates through `A(at, out, r, kind)` data attributes. New pages (`sortie-*.html`, `lexique.html`, `halloween-reel.html`…) are only their content; copy one of them to start a post. On each slide, place the dashed path with `track(k, y, amp)` in an empty band.
- The wordmark is HTML text in Outfit 800 with the gradient Z and its three ghost Zs (`wordmark()` in every page). Never put the Z in an SVG `<text>` loaded through `<img>`: it cannot reach the web font and falls back to a serif.
- Design tokens: dark backgrounds `#0B0812 → #131020 → #1B1330 → #150E22`, light `#FFFFFF → #F6F4FA`; accent `#C4B5FD` (dark) / `#7C3AED` (light); brand gradient `#FF4FA0 → #8B3DFF → #3AA9FF`; up `#5FD3A3`, down `#F0899A`; game colours e.g. Pokémon `#F5C93B`, Lorcana `#35C6BC`.
- **Highlights** (the circles under the profile): `a-la-une.html` draws one cover per post type of `TYPES.md`, exported to `images/a-la-une/<nn>-<type>.jpg`. Neither the Instagram, Facebook nor TikTok API (nor Metricool) can create or fill highlights: the user adds each story to its highlight by hand. A new post type gets a cover the same way.
- `rendu.mjs` imports Playwright from `/opt/node-tools/node_modules/playwright` (the cloud container's copy, with Chromium preinstalled). Outputs go to `gabarits/sortie/`, which is gitignored.

## Data

- **Price movers** (`donnees/cotes/pokemon/`): `.github/workflows/cotes.yml` runs `outils/cotes.py` on the 1st and the 16th of each month (or by hand: Actions › Cotes › Run workflow). It records the Cardmarket figures of every Pokémon card from TCGdex, then writes `top-<date>.json` with the 10 biggest moves since the previous record and their card images. For the template: `echo "window.TOP = $(cat ../donnees/cotes/pokemon/top-<date>.json);" > cotes-donnees.js`.
- **Daily record of a new set** (`donnees/cotes/pokemon/quotidien/<set>/`): `.github/workflows/cotes-quotidien.yml` runs `outils/cotes.py quotidien` every day at 05:23 UTC and records every card of the set named in `QUOTIDIEN` while today is inside its window (Règne Delta, 06/11 to 06/12/2026), for "Un mois après la sortie" (type 33). Outside the window it does nothing; point it at the next big release when one post is done.
- **Sealed prices** (`donnees/scelles/`): the same Cotes workflow runs `outils/scelles.py releve` after the cards (or alone: `etape: scelles`), recording the TCGplayer market price (USD, English editions) of every sealed product of the 8 games from the last five years, through tcgcsv within its rules; `python3 outils/scelles.py ecarts <game>` lists the moves between the last two records, for "Le radar des scellés" (type 35).
- **Graded prices** ("Brute ou gradée ?", type 34): read-only from the app's eBay listing cache (`MarketplaceListing`, Supabase project `uetvtyaruosulxsuolpe`), listings only, never a table about members; the query is in the header of `gabarits/brut-ou-gradee.html`. A company/grade row needs at least 3 listings; these are asking prices and the slide says so.
- **Network from the cloud container**: only `raw.githubusercontent.com` and git over HTTPS get out. TCGdex, Cardmarket, TCGplayer, Scryfall and the image CDNs are blocked here, but reachable from GitHub Actions, which is why the price records run there. Card images for posts: the `images/` folder written by the workflow, `type-null/PTCG-database` (Pokémon, English scans; blobless clone, then check out one file), or the **Image** workflow (`.github/workflows/image.yml`, run with `actions_run_trigger`): it downloads a page's og:image, an `<img>` matching a word, or a direct URL into `gabarits/assets/`; it also reads card APIs (Lorcast, Scryfall: give the JSON URL and a word of the image URL as motif), and its `lot` input fetches several images in one run, one `nom | url | motif` per line. Some sites answer 403 to it (Heritage, Fandom); shop and fan sites usually work. Always prefer the real card scan to a redrawn card.
- WebSearch works; WebFetch is mostly blocked. Quote figures from search results only with their source and date.

## Repo conventions
